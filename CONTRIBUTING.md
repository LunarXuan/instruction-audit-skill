# Contributing

Use Python 3.10+ and run `python -m unittest discover -s tests -v`. Keep model execution in the host; no credential extraction or implicit paid API fallback. Add behavioral tests for record validation and result interpretation when changing them.

Keep SKILL.md concise and put host-specific details in references. Test future host adapters against actual tool schemas. Preserve failure rows, unknown metadata and isolation limitations. Do not market mock or toy runs as model-capability evidence.
