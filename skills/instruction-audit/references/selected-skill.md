# Evaluate the user's selected Skill

Resolve the exact requested Skill folder or SKILL.md. A named installed Skill may exist in several scopes; inspect the host's known catalog/locations and clarify only ambiguous matches. Record its entry point and the evaluation scope. Do not scan unrelated private folders.

Inspect SKILL.md and referenced resources as needed. Separate instruction text, required scripts/tools, reference material and mandatory rules. Design tasks from the Skill's actual promised outcomes; arithmetic examples are unsuitable for judging a document-production or research Skill. Include failure-prone cases and checks for expected artifacts. Keep candidate-development tasks separate from held-out evaluation.

The text helper accepts `--target PATH` on `audit.py prepare` and `build_agents.py`. PATH is AGENTS.md, SKILL.md or a directory containing SKILL.md. It reads the selected entry point into the original condition and records target metadata. It does not automatically load linked resources, run scripts or install a Skill. Protected text and candidate text remain explicit fields in the case; review protected text before launch because the loader cannot identify every mandatory rule.

For an instruction-content comparison, keep required resources, tools, data and permissions available equally in all conditions. The coordinator supplies equal relevant resource context or separate copies for artifact tasks. Avoid reference files that themselves reload the optional instructions in the without condition. If resources cannot be separated, explain the confounding factor. A shorter prompt is not evidence that a script or reference library is dispensable.

To test the entire Skill package (including discovery/triggering and scripts), explicitly define a separate host-native test with installed/enabled and disabled conditions. Record actual loading and tool-use evidence. The bundled text helper does not implement that experiment; do not label a SKILL.md text comparison as whole-package compatibility or recommend deleting the whole package from it.

Recommendations should identify the affected section or resource: keep the operational rules, shorten redundant prose, fix a stale command, retain a required script, or propose a conditional disable trial. If the user names multiple Skills, use separate cases and report per Skill unless interactions are explicitly being tested. Generated records contain the selected path; redact private paths before publishing.
